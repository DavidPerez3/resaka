# RESAKA

**Los datos que no recordabas.**

RESAKA es una app móvil social y humorística para registrar salidas: recorrido, garitos, cervezas, kalimotxos, chupitos y copas.

## Estado

Proyecto recién inicializado con Expo + React Native + TypeScript + Expo Router.

La prioridad es construir primero el flujo principal:

1. Empezar salida
2. Registrar la noche
3. Terminar salida
4. Descubrir qué pasó

## Desarrollo

```bash
npm install
npm start
```

Durante estas primeras iteraciones usaremos Expo SDK 54 para poder probar fácilmente en un dispositivo físico con Expo Go. La arquitectura se mantendrá preparada para development builds y funcionalidades nativas más avanzadas.
